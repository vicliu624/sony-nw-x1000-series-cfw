# Homebrew icon regression fix

The source-built dev21 firmware reused stock Settings texture63 for the Sony
Homebrew entry. It omitted the dedicated shadow texture and catalog-count fix
that had already been accepted in the earlier candidate series.

Dev22 restores texture139 in both extended Home tables, appends the existing
64x64 BGRA shadow artwork from assets/icons/homebrew-shadow-v2-64.png, and raises
the compiled group catalog count from139 to140. Stock textures remain identical.
The icon asset is built from maintained PNG source, not an old candidate UPG.

Relative to the delivered dev21 image, only three SpiderApp bytes and
TEXGRP00.DAT change. The language cache, other root files/metadata, installer,
kernel and initrd are preserved. Existing external apps need no reinstall.

The final-image regression check reproduces failure on dev21 and passes on
dev22. It checks both Home tables, catalog count, exact accepted icon pixels and
all original texture bytes. Original ARM catalog replay resolves handle139.
Independent Rockbox extraction and a148MiB stock ext2 model pass; the model has
29003776 nonreserved bytes free. These are not a new physical flash/display or
failure-recovery acceptance report. Updating remains a manual user operation.
