# X1000 v0.1.0-dev.21 (experimental)

This release updates the external application launcher, app packages and QQ Music
for Japanese Sony NW-X1050/NW-X1060. The physical reference model is NW-X1060.

## Changes

- Applications now own their source, icons, descriptions, versions and build
  definitions. A shared command builds and packages each app independently.
- The launcher reads icons and summaries from installed app packages; new app IDs
  no longer require a compiled-in icon registration. Invalid resources use a
  generic fallback. Remote market icons remain generic before payload download.
- The app market shows descriptions, changes and installed/available versions,
  with explicit update, reinstall and downgrade confirmation.
- QQ Music 0.1.1-alpha.3 includes collection artwork thumbnails, missing-cover
  retrieval, sample-based conversion progress and clearer import-stage reporting.
  Wi-Fi preparation, installation identity and session clock handling are retained.
- Developer documentation now includes the native application specification.

The public audio-preview adapter remains disabled. Experimental preview source
is available for research; its presence is not hardware playback qualification.
Pet and QQ Startup Check have source definitions but are not public app packages
in this release. Pet's private character sprites are not redistributed.

## Updating

For an existing compatible Homebrew installation, update the external launcher
from player-setup and copy the required app packages to visible user storage.
Use market-source.zip to select this release's pinned application catalog. The
market cannot replace its own running executable: update it through the computer.
Retain your previous working packages and keep application data separate.

A firmware ZIP is also supplied for the matching Japanese platform. App updates
do not normally require reflashing. Copy player-setup files before using the
Homebrew entry. Never substitute international NWZ-X or other Walkman firmware.

## Validation and limits

Packages undergo native ARM/QEMU, manifest, inventory, catalog and installation
checks. Firmware verification checks that the original installation script,
kernel and initrd remain unchanged and checks expanded filesystem capacity.
These checks do not establish safe recovery from failed flashing or qualify
sleep, RF/audio and every application on physical hardware. Flash at your own risk.

No ROMs, saved games, account data, music, private TLS keys or original SDK
libraries are included in the application packages. Terminal needs personal PC
pairing; QQ Music needs your own account, existing Wi-Fi and a valid TLS clock.
