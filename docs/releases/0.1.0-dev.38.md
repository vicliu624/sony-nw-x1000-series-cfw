# NW-X1000 0.1.0-dev.38

Experimental firmware for Japanese NW-X1050 and NW-X1060 using Sony 1.11.

- Wireless Remote and ordinary Wi-Fi share the radio. Playback, the five Sony
  play modes, library browsing and cover display use the matching Core2 with
  Faces Bottom3 and Gamepad3.
- A cover request now retrieves up to eight consecutive chunks. Playback
  commands can run between chunks. The controller resumes from the last
  verified offset after a missing chunk and displays the image once it is ready.
- The firmware keeps Japanese, English, Simplified Chinese and Traditional
  Chinese in Sony Settings. The Homebrew setup contains the launcher, Store
  and catalog configuration. Application ZIPs are available separately.
- The standalone source SDK release is `sdk-v0.2.0-alpha.14`. The SDK exposes
  ESP-NOW and player control as separate services.

Use the firmware ZIP with the original Japanese Sony 1.11 update tool. Copy the
player setup to the WALKMAN user volume before opening Homebrew. For Wireless
Remote, use the Core2 application ZIP from this release. On the verified Core2
layout, write the image at application offset `0x10000` after checking the
board and its partition table. An application-only write preserves the
partition table and pairing storage.

The owner tested this exact UPG and Core2 application on an NW-X1060. The
diagnostic build can measure the shared radio through the paired Core2 console.
In an earlier same-image comparison, an 85,474-byte cover transferred in 5.76 s
with periodic screen draws and 3.71 s with those draws suppressed. The release
uses the latter redraw policy. Results vary by image and link conditions.

Flashing rewrites the system partition and can make the device unbootable if
installation fails or is interrupted. This release has partial NW-X1060
hardware acceptance. USB and sleep/wake cases and the NW-X1050 still have
unverified behaviors. See the project status for the scope of the hardware tests.
